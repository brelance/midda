# 阅读器目录功能实现计划

## 任务分级
- 等级：中等 —— 需要新建目录侧栏组件、管理显示状态，并与章节跳转逻辑集成。

## 实现步骤
1. 梳理并确认现有章节数据结构与跳转函数（`ReaderPage` 中的 `chapters`、`goToChapter` 等）。
2. 定义目录侧边栏组件（或直接在 `ReaderPage` 中渲染），实现蒙层、滑入式面板、当前章节高亮、关闭按钮。
3. 在 `ReaderPage` 增加目录开关状态，处理 `ReaderHeader` 的 `onOpenToc` 回调，支持快捷键调用。
4. 为目录项绑定章节跳转逻辑：点击后调用 `goToChapter`、关闭侧栏，并短暂显示工具栏。
5. 增加必要样式（Tailwind）以匹配既有昭和复古粗野主义风格，确保在主容器层级正确渲染。
6. 自测：验证按钮/快捷键可打开目录，当前章节高亮，点击可跳转并关闭目录，滚动及其他工具栏功能正常。
