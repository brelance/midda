# Reader Settings Modal Responsiveness Plan

## 背景
当前阅读器的设置弹窗固定在 `500px` 宽高附近，内部 padding 和分区高度也比较大。当窗口高度减小时，弹窗可能超出视窗，导致部分内容不可见或遮挡关闭按钮，需要滚动外层页面才能操作，影响体验。

## 目标
- 弹窗在小屏幕或高度受限时依然完整可见。
- 弹窗内容区在需要时出现内部滚动，而不是整体溢出屏幕。
- 保持现有昭和复古粗野主义视觉风格（粗描边、阴影、按钮交互动效等）。

## 实施步骤
1. **梳理现有结构与尺寸约束**
   - 检查 `ReaderSettingsModal.tsx` 中容器宽度、高度和 padding 设定。
   - 评估 `ReaderSettingsModal` 使用的 Tailwind 类，对影响响应式的属性（如 `px-6`, `py-6`, `max-w-[500px]`、固定阴影偏移等）做记录。

2. **设计响应式策略**
   - 设置弹窗容器的最大高度 `max-h`，并让主体内容区 `overflow-y-auto`。
   - 针对移动端或中等尺寸屏幕调整 padding / gap，以减少占用。
   - 为横向尺寸设计断点：在极窄屏幕下可降低 `max-w`、改用 `w-full` 与更小的 `border-radius`。

3. **实现并验证**
   - 更新 `ReaderSettingsModal.tsx` 样式类，实现自适应布局与可滚动内容。
   - 确保外层遮罩在滚动时固定（`overflow-hidden`），键盘关闭逻辑仍正常。
   - 使用浏览器开发者工具模拟不同视口，验证关闭按钮、选择控件、阴影效果仍可用。

4. **后续兼容性检查（可选）**
   - 如果后续新增设置项，应确认新增内容同样遵循滚动区域逻辑。
   - 若有全局的 Tailwind 主题调整，确保该弹窗样式不破坏统一视觉。
